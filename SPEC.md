# HolyScreen — спека

Лёгкая Windows-утилита для скриншотов с аннотациями (в духе ShareX/Lightshot). Живёт в трее, главного окна нет.
По хоткею выделяешь область, рисуешь поверх и одной кнопкой копируешь в буфер или сохраняешь.

> Исходная спека + ответы на уточняющие вопросы (2026-10-23). Этот файл — источник правды по решениям.

## Решения

| Тема | Решение |
|---|---|
| Стек | C# / .NET 10 + WPF, `net10.0-windows10.0.17763.0`. Без прав админа. |
| Стекло | **Frosted, как в Password Helper**: блюр реальных пикселей под панелью + полупрозрачный графит + тонкая светлая обводка, та же палитра. Выбрано вместо настоящего Liquid Glass (рефракция HLSL-шейдером), чтобы снять риск. |
| Тулбар | **Две панели, как Lightshot**: инструменты вертикально справа от выделения, действия горизонтально снизу. |
| Аннотации | **Редактируемые объекты**: выбрать, двигать, ресайзить ручками, менять цвет/толщину/текст, Del. |
| Хоткей | **`Alt+Shift+S`** (настраиваемый). Только `RegisterHotKey`, без низкоуровневых хуков клавиатуры. |
| Язык UI | **English**. Все строки в одном месте, чтобы локализацию можно было добавить позже. |
| Copy | **Копирует и закрывает** (Ctrl+C / Enter / двойной клик по области). С Shift — скопировать и остаться. Переключается в настройках. |
| Доп. фичи | + **Beautify** (фон, отступ, тень, скругление), + лупа у курсора, + повтор последней области. |
| Не делаем (пока) | Загрузка и ссылки, скролл-захват, запись GIF/MP4. |
| Тест mixed-DPI | На время тестов второй монитор → 150% через DisplayConfig API, потом обратно 100%. |

## Основной флоу

1. `Alt+Shift+S` → мгновенно снимается кадр всех мониторов; поверх каждого монитора — окно с этим **замороженным**
   кадром, затемнённым. Курсор-крестик, лупа у курсора.
2. Наведение подсвечивает окно под курсором (магнит); клик без драга = захват окна. Зажал ЛКМ и тянешь = область
   (размер в px рядом, Shift — квадрат).
3. Отпустил → выделение остаётся редактируемым (ручки, стрелки ±1 px, Shift+стрелки ±10 px), появляются две панели.
4. Esc — отмена в любой момент (во время ввода текста сначала завершает ввод).

Клавиши до выделения: `F` — весь монитор под курсором, `C` — пипетка, `O` — OCR-режим, `R` — повтор последней области.

## Оверлей

- **Замороженный кадр в непрозрачном окне, а не прозрачное окно.** `AllowsTransparency=True` = layered window:
  каждый кадр всё окно копируется GPU→CPU, на больших разрешениях анимации проседают. Замороженный кадр даёт полный
  GPU-рендер, захватывает ровно то, что было на экране в момент нажатия (тултипы, открытые меню), и мы знаем пиксели
  под каждой панелью — это нужно для frosted-эффекта.
- **Окно на каждый монитор**, каждое со своим DPI → панели чёткие и правильного размера. Общий контроллер выделения
  работает в физических пикселях виртуального экрана, поэтому выделение через стык мониторов тоже работает.
- Затемнение вне области, рамка, бейдж размера, лупа (зум пикселей + координаты + цвет под курсором).
- Магнит к окнам: границы через `DWMWA_EXTENDED_FRAME_BOUNDS` (иначе +7 px невидимой рамки), cloaked-окна
  пропускаем, z-order снимаем в момент нажатия хоткея.

## Панели (Lightshot-раскладка, frosted)

- **Инструменты** — вертикально справа от выделения (если не влезает — слева или внутри): стрелка, прямоугольник,
  эллипс, линия, карандаш, текст, маркер, пикселизация, шаги; внизу — свотч цвета (открывает палитру) и толщина.
- **Действия** — горизонтально под выделением (если не влезает — над ним или внутри):
  Undo, Redo · Pin, OCR, Beautify · Save, Copy · Close.
- Толщина меняется колесом мыши при активном инструменте (с бейджем значения), как в Lightshot. Если выбран объект,
  цвет и толщина применяются к нему.

## Инструменты аннотации

- Стрелка; прямоугольник/эллипс (контур, Shift — квадрат/круг); линия (Shift — шаг 45°); карандаш (со сглаживанием);
  текст (цвет, размер, правка по двойному клику); маркер (полупрозрачная заливка); пикселизация (по умолчанию крупный
  блок + режим «сплошная заливка»); шаги (кружки 1, 2, 3… с автонумерацией).
- Редактирование: наведение на объект → курсор перемещения; клик — выбрать, драг — двигать, ручки — ресайз
  (у стрелки и линии — концы), Del — удалить.
- Undo/Redo: `Ctrl+Z` / `Ctrl+Y` (и `Ctrl+Shift+Z`).
- Пикселизация считается на CPU по реальным пикселям, а не шейдером: экспорт через `RenderTargetBitmap` рендерит
  программно и ps_3_0-эффекты не рисует. Крупный блок по умолчанию — потому что мелкую пикселизацию текста
  восстанавливают (Depix).

## Действия

- **Copy** — итоговое изображение со всеми аннотациями в буфер: PNG + DIB (браузеры и мессенджеры берут PNG, старые
  приложения — DIB), с ретраями, если буфер занят другим процессом. По умолчанию копирует и закрывает; Shift — остаться.
- **Save** — PNG (или JPG) в `Pictures\Screenshots` через KnownFolder `FOLDERID_Screenshots` (иначе промах, если
  Pictures перенесены в OneDrive). Имя `Screenshot_2026-10-23_14-05-01.png`, при коллизии — `_2`. По аналогии с Copy:
  сохраняет и закрывает, Shift — остаться; тост «Saved · Show in folder».
- Опция: автокопия в буфер сразу после выделения.

## Приколы

- **Pin to screen** — плавающее always-on-top окно: драг, колесо — зум, Ctrl+колесо — прозрачность, двойной клик или
  Esc — закрыть.
- **OCR** — `Windows.Media.Ocr`. Из коробки есть en-US и ru (uk нет — нужен языковой пакет Windows). Движок работает
  по одному языку, поэтому прогоняем доступные и берём лучший результат.
- **Пипетка** — HEX в буфер (Shift — RGB).
- **Захват окна** — клик по подсвеченному окну.
- **Таймер** — 3/5 с из меню трея, обратный отсчёт тостом.
- **История** последних N скринов: хранится исходник + слои аннотаций (JSON) → можно переоткрыть и дорисовать или
  перекопировать.
- **Повтор последней области.**
- **Beautify** — отдельное окно-превью: фон (градиенты или цвет), отступ, скругление, тень; Copy/Save оттуда
  (PNG с альфой).

## Настройки (из трея)

- Хоткей + дополнительные хоткеи (весь экран, повтор области, OCR, пипетка) — по умолчанию не назначены.
- Папка сохранения, формат (PNG/JPG + качество), шаблон имени.
- Copy: закрывать после копирования; автокопия после выделения.
- Звук/вспышка при захвате, цвета и толщина по умолчанию.
- Автозапуск (HKCU `Run`), анимации (уважаем системный тумблер «Эффекты анимации»).

## Архитектура и технические решения

- Структура как у Password Helper: `src/HolyScreen`, `tests/HolyScreen.Tests`, `HolyScreen.slnx`, `build.ps1`
  (находит per-user .NET SDK), `dist/`.
- Переиспользуем из Password Helper: TrayIcon, HotkeyManager / HotkeyGesture / HotkeyRecorder, SingleInstance,
  StartupRegistration, Log, SettingsService, MessageWindow, ToastService, тему, `Interop/Win32.cs` (весь P/Invoke —
  в одном файле).
- Процесс PerMonitorV2 (через manifest).
- Захват: `BitBlt` + `CAPTUREBLT` в DIB section → `BitmapSource`, без System.Drawing.
- Экспорт: свой рендер документа в `DrawingVisual` → `RenderTargetBitmap` строго 1:1 в физических пикселях.
- Документ: модель объектов + стек команд (Undo/Redo); сериализуется в JSON для истории.
- Анимации: пружинные, прерываемые; ввод никогда не ждёт анимацию (рамку можно тянуть с первого кадра).
- Данные: `%LOCALAPPDATA%\HolyScreen\` (settings.json, logs, history).

## Этапы

1. **Скелет:** solution + `build.ps1` + git; трей (Capture, Settings, Exit) + `Alt+Shift+S` + захват всего экрана в PNG.
2. **Оверлей выделения:** замороженный кадр на каждом мониторе, затемнение, крестик, размер в px, лупа, ручки
   выделения, магнит к окнам; mixed-DPI (тест на 150%).
3. **Экспорт + Copy/Save** + две frosted-панели (пока без инструментов).
4. **Модель документа + Undo/Redo первыми**, затем инструменты по одному: стрелка → прямоугольник/эллипс → текст →
   линия/карандаш → маркер → пикселизация → шаги; выбор, перемещение, ресайз.
5. **Приколы:** pin, OCR, пипетка, захват окна, таймер, история, повтор области, Beautify.
6. **Настройки + полировка:** DPI edge-cases, звук, анимации.

## Тестирование

- **Юнит:** DPI- и координатная математика, шаблон имени и коллизии, настройки, хоткеи, модель документа и Undo/Redo,
  экспорт (рендер известной сцены → сравнение пикселей), пикселизация, буфер (запись → чтение), OCR на
  сгенерированной картинке (en/ru).
- **Смоук на живой системе:** запуск, хоткей через `SendInput`, оверлей на обоих мониторах, Copy/Save, Esc, выход
  без висящих процессов.
- **Mixed-DPI:** второй монитор → 150% через DisplayConfig API на время тестов, затем обратно 100% — всегда, даже
  если тест упал.
- **Железо:** 2 × 1920×1080 @ 100%, Windows 11 build 26200.
